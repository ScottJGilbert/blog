## Notes

- Mobile Performance varies by about 2 points between runs (94-99 observed during iteration). Lighthouse mobile LCP is a *simulated* value: on localhost every font/script that arrives before the first paint is replayed at Slow-4G speed, so it tracks transferred bytes (React + Next runtime is about 150 KB gzip of JS, fonts about 40-60 KB). The *observed* LCP in the same runs is about 0.15 s.
- Independent in-browser measurement (Playwright + CDP, Slow 4G 1.6 Mbps / 150 ms RTT, 4x CPU, cold cache, 412x823): LCP 0.66-0.75 s and CLS 0 on /, /personal, /engineering, /about.
- Fonts use next/font with display: "optional" and preload, so a late font can never re-wrap text and shift layout; on very slow first visits the size-adjusted fallback stays for that page view.
